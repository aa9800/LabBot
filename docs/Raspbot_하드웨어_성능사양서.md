# Yahboom Raspbot — 하드웨어 성능 사양서 & 활용 분석 (실물 확인판)

> **기준**: 야붐 웹사이트 제품군 공통 스펙이 아니라,  
> 실물 로봇 내부 `~/Yahboom_project/Raspbot/2.Hardware Control course/` 및  
> `dir(YB_Pcb_Car())` 결과를 기준으로 작성.  
> **추가 하드웨어 없이 소프트웨어만으로** 개선 가능한 부분을 분석.

## 1. 하드웨어 전체 인벤토리

### 🧠 메인 컴퓨터
| 항목 | 사양 |
|---|---|
| **보드** | Raspberry Pi 5 (4GB RAM) |
| **CPU** | Broadcom BCM2712, Quad-core Cortex-A76 @ 2.4GHz |
| **GPU** | VideoCore VII (OpenGL ES 3.1, Vulkan 1.2) |
| **I/O** | PCIe 2.0 x1, 2× USB 3.0, 2× USB 2.0, 40-pin GPIO |
| **통신** | Wi-Fi 5 (802.11ac), Bluetooth 5.0, Gigabit Ethernet |
| **OS** | Raspberry Pi OS 64-bit (Bookworm) |

### 🔌 확장보드 (Yahboom 다기능 드라이버 보드)
| 항목 | 사양 |
|---|---|
| **MCU** | STM8 코프로세서 (모터/서보 PWM 생성 전담) |
| **통신** | I2C (Raspberry Pi ↔ STM8) |
| **전원** | 5V/5A, 배터리 → Pi5 직접 전원 공급 |
| **라이브러리** | `YB_Pcb_Car.py` |

### YB_Pcb_Car 사용 가능한 API (dir 확인)
```
Control_Car(left, right)    # 모터 (좌/우 2채널 믹싱)
Car_Stop()                  # 정지
Ctrl_Servo(id, angle)       # 서보 제어 (1=Pan, 2=Tilt)
Ctrl_Buzzer(on_off)         # ※ 동작 안 함 — 패시브 부저라 PWM 필요
```

> [!CAUTION]
> **존재하지 않는 API** (야붐 웹사이트에서 상위 모델 기준으로 기재된 것):
> - ❌ `Speed_Wheel_control(A,B,C,D)` — 4바퀴 독립 제어 불가
> - ❌ `Ctrl_RGB(R,G,B)` — RGB LED 없음
> - ❌ OLED 디스플레이 — 미장착 (하드웨어 강좌 10개에도 없음)

## 2. 센서 & 액추에이터 상세

### 📷 카메라 (CSI OV5647, 5MP)
| 항목 | 값 | 비고 |
|---|---|---|
| **센서** | OV5647 (CSI 인터페이스) | 부팅 로그에서 확인 |
| **최대 해상도** | 2592×1944 (5MP) | 스트리밍 시 320×240 사용 |
| **현재 해상도** | 320×240 | `CAMERA_SIZE` 설정 |
| **FPS** | 30fps (하드웨어 고정) | `FrameDurationLimits: 33333` |
| **마운트** | 2DOF Pan-Tilt (서보 2개) | Pan: Servo1, Tilt: Servo2, 각 0~180° |
| **색보정** | Saturation 1.4, AWB Auto | `libcamera` + `picamera2` |
| **용도** | FPV 스트리밍, QR 인식, AI 객체 탐지 | `picamera2` + `pyzbar` |

**현재 활용도: ★★★★☆**
- ✅ 실시간 MJPEG 스트리밍 (8080 포트)
- ✅ QR 코드 인식 (온디맨드)
- ✅ AI 비전 서버로 프레임 전송 (PC 오프로딩)
- ✅ Pan-Tilt 원격 조작

> [!TIP]
> **추가 활용 가능**:
> - 해상도 동적 전환: 평소 320×240 → AI 트리거 시 640×480으로 올려 정밀 촬영 후 복귀
> - OV5647은 5MP까지 가능하므로 스냅샷 시 고해상도 캡처도 가능

---

### 🔊 초음파 센서 (HC-SR04)
| 항목 | 값 | 비고 |
|---|---|---|
| **핀** | Trig=BOARD 16, Echo=BOARD 18 | GPIO.BOARD 모드 |
| **측정범위** | 2cm ~ 400cm | 타임아웃 0.03초 |
| **정밀도** | ±3mm | 온도 보정 없음 |
| **갱신속도** | ~20Hz (50ms/회) | 트리거 간 최소 대기 포함 |
| **출처** | `04.Ultrasonic Ranging/Ultrasonic Ranging.ipynb` |

**현재 활용도: ★★☆☆☆ (과소 활용)**
- ✅ 장애물 회피 (40cm 이내 정지)
- ❌ 그 외 용도 없음

> [!IMPORTANT]
> **추가 활용 가능 (소프트웨어만으로)**:
> 1. **침입 감지 트리거**: 정지 상태에서 초음파 거리값이 갑자기 변하면 → "뭔가 지나갔다" → AI 탐지 활성화.
>    - 배경 거리를 5초간 평균으로 기록 → 이후 ±30cm 이상 변화 시 트리거
>    - PIR 센서 없이도 비슷한 효과
> 2. **사람 접근 경고**: 순찰 정지 시 1m 이내 접근 감지 → 부저 경고음

---

### 🛤️ 라인트래킹 센서 (4채널 IR 반사형)
| 항목 | 값 | 비고 |
|---|---|---|
| **채널** | 4개 (Left Outer/Inner, Right Inner/Outer) |
| **핀** | BOARD 15, 13, 11, 7 | GPIO.IN, Active LOW |
| **감지** | 검은 선 위 = LOW → `not GPIO.input()` = True |
| **출처** | `07.Tracking/Tracking.ipynb` |

**현재 활용도: ★★★☆☆**
- ✅ 자동 순찰 경로 추종 (검은 테이프 경로)

> [!TIP]
> **추가 활용 가능**:
> 1. **구역 마커 인식**: 4채널 동시 감지 패턴으로 교차점 구분 가능 (예: 4개 전부 ON = 십자 교차점)
> 2. **경로 이탈 알림**: 4채널 전부 OFF 지속 시 "로봇이 경로를 이탈했습니다" 웹 알림

### 🔔 부저 (패시브, PWM 구동)
| 항목 | 값 | 비고 |
|---|---|---|
| **핀** | BOARD 32 | GPIO.OUT → PWM |
| **타입** | 패시브 부저 | HIGH/LOW만으로 안 울림, PWM 필수 |
| **주파수** | 440Hz (기본) | **변경 가능 (200~2000Hz)** |
| **듀티** | 50% = 최대 음량 | 0% = 무음 |
| **출처** | `01.Drive buzzer/Buzzer_test.ipynb` |

**현재 활용도: ★★★☆☆**
- ✅ 침입자 감지 시 경보 (440Hz 고정)
- ✅ 웹 버튼으로 수동 테스트

> [!TIP]
> **추가 구현 완료 (이번 작업)**:
> - `buzz_success()`: 880Hz 단음 1회 (QR 스캔 성공)
> - `buzz_warning()`: 660Hz × 2회 (경고)
> - `buzz_siren()`: 1000Hz↔400Hz 교대 반복 (침입자 경보)
> - `trigger_buzzer()`: 440Hz 삑-삑 패턴 (기존)

---

### 💡 LED (BOARD 38=파랑, BOARD 40=빨강)
| 항목 | 값 | 비고 |
|---|---|---|
| **타입** | 단순 ON/OFF LED 2개 | GPIO.HIGH = 켜짐 |
| **색상** | 파랑(38), 빨강(40) | 혼합 불가 — 동시 켜면 "파랑+빨강" |
| **밝기** | 표시등 수준 | 경보용으로는 부족 |

**현재 활용도: ★☆☆☆☆ → ★★★☆☆ (이번 작업으로 개선)**

> [!IMPORTANT]
> **구현 완료 (이번 작업)**:
> - `set_status_led("patrol")`: 파랑 ON — 자동 순찰 중
> - `set_status_led("alert")`: 빨강 ON — 침입자/긴급
> - `set_status_led("manual")` / `set_status_led("ai")`: 파랑+빨강 — 수동/AI 모드
> - `set_status_led("off")`: 전부 끔
> - `flash_alert_led()`: 빨강 LED 고속 깜빡임 (침입 감지 시)

---

### 🛞 모터 (좌/우 2채널 믹싱, 메카넘 휠)
| 항목 | 값 | 비고 |
|---|---|---|
| **바퀴** | 4× 메카넘 휠 (물리적 장착) | |
| **API** | `Control_Car(left, right)` | 좌/우 2채널만 지원 |
| **속도** | 부호 있는 값, +전진 -후진 | PWM 0~100 |
| **출처** | `07.Tracking/YB_Pcb_Car.py` |

**현재 활용도: ★★★☆☆**
- ✅ 전진/후진/좌회전/우회전

> [!WARNING]
> **한계**: 메카넘 휠이 물리적으로 장착되어 있지만 `Speed_Wheel_control(A,B,C,D)` API가  
> 존재하지 않으므로 **측면 이동(스트레이프), 대각선, 제자리 360° 회전은 구현 불가**.  
> `Control_Car(left, right)`로 가능한 것:
> - 전진/후진: `Control_Car(70, 70)` / `Control_Car(-70, -70)`
> - 좌회전: `Control_Car(-50, 50)` (제자리) 또는 `Control_Car(30, 70)` (완만)
> - 우회전: `Control_Car(50, -50)` 또는 `Control_Car(70, 30)`
>
> 360° 감시를 하려면 제자리 회전 + Pan-Tilt 카메라 조합으로 대응 가능.

## 3. 현재 아키텍처 vs 개선 아키텍처

### 현재 구조
```
[라즈봇 Pi5]                          [사용자 PC]
  CSI 카메라 30fps 항상 가동              AI 서버 (8081)
  → MJPEG 스트리밍 (8080)  ──Wi-Fi──→   매 프레임 YOLO 풀가동
  초음파: 장애물 회피만                    바운딩 박스 렌더링
  부저: 440Hz 고정                       → 웹 대시보드 (3000)
  LED: 꺼짐
  모터: 2채널 전진/후진/회전만
  라인센서: 순찰 경로만
```

### 제안 구조 (추가 하드웨어 없음)
```
[라즈봇 Pi5]                          [사용자 PC]
  CSI 카메라 30fps                       AI 서버 (8081)
  → MJPEG 스트리밍 (8080)  ──Wi-Fi──→   ★ MOG2 배경차분 1차 필터
  초음파: 장애물 회피                      → 움직임 영역만 YOLO (연산 70%↓)
       ★ + 침입 트리거 (거리 변화 감지)    바운딩 박스 렌더링
  부저: ★ 상황별 주파수 멜로디              → 웹 대시보드 (3000)
  LED: ★ 파랑/빨강 상태 표시등
  모터: 2채널 + 제자리 회전 (감시 회전)
  라인센서: 순찰 경로 + 교차점 감지
```

## 5. 핵심 인사이트

> [!CAUTION]
> **실물 확인으로 걸러진 것들 (야붐 웹사이트 vs 실제):**
> 
> | 야붐 웹사이트 (상위 모델 공통) | 실물 (이 개체) |
> |---|---|
> | `Speed_Wheel_control(A,B,C,D)` 4바퀴 독립 | ❌ 없음, `Control_Car(L,R)` 2채널만 |
> | `Ctrl_RGB(R,G,B)` RGB LED | ❌ 없음, BOARD 38/40 ON/OFF LED 2개 |
> | SSD1306 OLED 디스플레이 | ❌ 미장착 |
> | USB 1MP 카메라 | ❌ 아님, CSI OV5647 5MP |
>
> **소프트웨어로 확실히 활용 가능한 것들:**
> 1. **초음파 침입 트리거** — 정지 시 거리 변화 감지 → PIR 대체
> 2. **MOG2 배경 차분** — 움직임 프레임만 YOLO → 연산 70% 절약
> 3. **부저 멜로디** — 패시브 부저 주파수 가변으로 상황별 사운드
> 4. **LED 상태등** — 파랑/빨강 2개지만 순찰/경보/수동 구분 가능
