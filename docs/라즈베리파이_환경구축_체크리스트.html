라즈베리파이 5 / Raspbot 환경구축 체크리스트

Raspbot + Raspberry Pi 5 실물이 아직 도착하지 않아서, 지금은 준비만 해두고 물건이 오면 이 문서 순서대로 진행하면 됩니다.

이미 준비된 것 (지금 PC에서 완료)
  • Raspberry Pi Imager 설치 완료 — SD카드에 OS를 구울 때 씀
  • robot-sim/real_hal.py — 5개 메서드 뼈대(TODO)만 미리 만들어 둠

왜 필요한가

지금까지 만든 controller.py(판단 로직)는 하드웨어를 몰라도 되도록 설계했지만, 실제로 모터를 돌리고 초음파·라인센서를 읽는 코드는 라즈베리파이 안에서 직접 실행돼야 합니다 (원격으로 PC에서 명령을 보내면 지연 때문에 안전정지 같은 반응이 느려짐). 그래서 라즈베리파이에 자체적으로 OS와 필요한 라이브러리를 설치하는 작업이 따로 필요합니다.

물건 도착 후 순서

1단계 — SD카드에 OS 설치

  1. Raspberry Pi Imager 실행
  2. OS: Raspberry Pi OS (64-bit) 선택 (Yahboom 예제가 32bit 기준일 수도 있으니, 예제 실행이 안 되면 64bit → 32bit로 바꿔서 재시도)
  3. 설정(⚙) 에서 미리 SSH 활성화, 와이파이 정보, 호스트명(예: labkeeper-pi) 입력해두면 모니터 없이도 바로 접속 가능

2단계 — 첫 부팅 & 접속 확인

  1. SD카드 꽂고 부팅 → 같은 와이파이에서 ssh labkeeper-pi.local (또는 IP 주소)로 접속
  2. sudo raspi-config 에서 Camera, I2C 인터페이스 활성화

3단계 — Yahboom 공식 자료 받기

  1. yahboom.net/study/Raspbot 학습 페이지 접속
  2. 다운로드 섹션에서 Code(예제 코드) 폴더 + 설명 매뉴얼(PDF) 받기 — 여기에 실제 모터/센서 제어 함수 이름이 들어있음 (지금은 이 문서에서 정확한 함수명을 확정할 수 없어서, 실물 도착 후 이 자료를 직접 열어서 확인해야 함)
  3. 매뉴얼대로 필요한 파이썬 라이브러리 설치 (보통 pip install 한두 줄)
  4. Yahboom 예제를 하나씩 따로 실행해서 아래를 개별 확인:
    • 모터 좌/우 바퀴 각각 회전하는지
    • 초음파 센서 값이 실제 거리에 맞게 나오는지
    • 라인(적외선) 센서 4개가 흰 바닥/검은 선을 구분하는지
    • 카메라로 사진이 찍히는지 (OpenCV)

4단계 — 우리 코드 올리기

  1. 라즈베리파이에서 git clone https://github.com/aa9800/LabBot.git
  2. robot-sim/real_hal.py를 열어서, 3단계에서 확인한 Yahboom 실제 함수를 이용해 5개 메서드(read_line_sensors / read_ultrasonic / try_read_qr / set_motion / stop)를 채움 — 이름과 반환값 형태는 sim/hal_sim.py와 똑같이 유지해야 controller.py를 안 고쳐도 됨
  3. 새 진입점 스크립트(또는 main.py 복사본)에서 SimHAL 대신 RealHAL()을 넣어서 실행
안전 주의사항
  • 처음 실물 테스트는 반드시 저속 + 사람이 바로 옆에서 지켜보며 진행
  • 바퀴를 바닥에서 띄운 상태(또는 받침대 위)에서 모터 회전 먼저 확인하고, 그 다음에 바닥에 내려서 이동 테스트
  • 이 단계는 발표 이후 작업입니다 — 월요일 발표는 Webots 시뮬레이션만으로 완결됩니다
