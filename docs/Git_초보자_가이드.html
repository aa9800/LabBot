완전 초보자용

Git, 이렇게만 하면 됩니다

지훈님도 Claude Code를 쓰시니, git 명령어를 몰라도 됩니다. 아래 문장을 그대로 복사해서 Claude한테 붙여넣으면 Claude가 대신 처리해줍니다.

0 시작 전에 딱 한 번, 직접 할 일

이 두 가지는 Claude가 대신 못 해줘서 직접 해야 해요.

  1. GitHub 계정이 없으면 github.com에서 가입
  2. 초대 이메일 또는 GitHub 알림 확인 → Accept invitation(초대 수락) 클릭

1 저장소 받기 — 딱 한 번만

Claude 채팅창에 이렇게 입력하세요:

클로드에게 말하기
https://github.com/aa9800/LabBot 이 저장소를 내 컴퓨터에 클론해줘

어디에 받을지 물어보면 원하는 위치(예: 바탕화면)를 말해주면 됩니다. 이 작업은 딱 한 번만 하면 됩니다.

2 작업 시작하기 전 — 매번

다른 사람이 먼저 올린 내용을 받아오는 단계예요. 작업 시작 전에 항상 먼저 하세요.

클로드에게 말하기
LabBot 저장소 최신 상태로 pull 해줘

3 작업 다 끝나고 — 매번

내가 고친 내용을 저장하고 다른 사람도 볼 수 있게 올리는 단계예요.

클로드에게 말하기
지금까지 작업한 거 커밋하고 push해줘. 커밋 메시지는 "로그인 화면 작업"으로 해줘

커밋 메시지는 예시일 뿐, 그날 뭘 했는지 한 줄로 바꿔서 말하면 됩니다.

4 뭔가 이상하거나 에러가 나면

클로드에게 말하기
지금 git 상태 좀 확인해줘

또는 화면에 뜬 에러 메시지를 그대로 복사해서 붙여넣고 "이거 무슨 뜻이야? 어떻게 해결해?"라고 물어보세요. "merge conflict"라는 말이 떠도 당황하지 마세요 — 흔한 일이고, Claude가 대부분 바로 풀어줄 수 있습니다.

5 이 세 단계만 기억하면 끝

시작 전
pull
작업
코드 수정
끝나고
commit + push

6 (참고) 최소한의 용어

저장소(repository) — 프로젝트 파일들이 모여있는 곳. 지금 우리껀 aa9800/LabBot
커밋(commit) — "이 시점 상태를 저장"하는 것. 사진 찍듯 스냅샷을 남기는 개념
푸시(push) — 내 컴퓨터의 내용을 GitHub(온라인)에 올리는 것
풀(pull) — GitHub에 있는 최신 내용을 내 컴퓨터로 받아오는 것
충돌(conflict) — 같은 부분을 두 명이 동시에 고쳤을 때 나는 알림. Claude한테 물어보면 대부분 해결됨

7 (선택) 직접 명령어로 해보고 싶다면

Claude 없이 터미널에 직접 입력해도 됩니다 — 필수는 아니에요.

git clone https://github.com/aa9800/LabBot.git
cd LabBot
git pull
git add -A
git commit -m "무슨 작업했는지"
git push
